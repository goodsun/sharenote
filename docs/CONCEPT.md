# 共有手帳(shareNOTE) - コンセプトドキュメント

## 🌸 命名の由来

### シェアする手帳

「共有手帳(shareNOTE)」は、家族みんなで共有する新しい形の手帳です。

- **共有手帳**: 家族で共有する、みんなの手帳
- **shareNOTE**: share（共有）+ NOTE（記録）
- **コンセプト**: 一人ひとりの気づきが、家族みんなの知恵になる
